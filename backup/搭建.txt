## 二、环境搭建步骤
### 1. 安装Linux系统（Install Linux OS）
- 支持系统版本：Ubuntu 16.0、Deepin 20.0
- 安装方式：
  1. 直接安装到PC（Install on PC directly）
  2. 先安装虚拟机，再在虚拟机中安装Linux（Install virtual machine first, then install Linux）

### 2. 搭建Hadoop环境（Build Hadoop Environment）
#### 2.1 JDK安装步骤
1. 下载并安装JDK
2. 配置环境变量
3. 验证安装结果：执行命令 `source /etc/profile` → `java -version`
   - 成功验证提示：`java version "1.8.0_261" Java(TM) SE Runtime Environment (build 1.8.0_261-b12) Java HotSpot(TM) 64-Bit Server VM (build 25.261-b12, mixed mode)`

#### 2.2 SSH安装步骤
1. 下载SSH
2. 配置SSH免密登录
3. 验证免密登录：执行 `ssh localhost`，成功提示 `Welcome to Deepin 20 GNU/Linux`
- 问题：Root用户授权失败
  解决方案：
  1. 执行 `sudo passwd` 修改root用户密码
  2. 修改sshd_config文件，将 `#PermitRootLogin prohibitpassword` 改为 `PermitRootLogin yes`
  3. 重启SSH服务

#### 2.3 Hadoop安装步骤
1. 下载Hadoop
2. 修改配置文件：core-site.xml、hdfs-site.xml、mapred-site.xml、yarn-site.xml、hadoop-env.sh
3. 配置环境变量
4. 启动Hadoop并通过JPS验证进程
   - 成功进程示例：NameNode（11280）、DataNode（11395）、ResourceManager（11691）、SecondaryNameNode（11547）、NodeManager（11775）
- 问题：配置文件修改正确但部分进程缺失
  解决方案：
  1. 执行 `./stop-all.sh` 停止所有服务
  2. 删除HDFS数据块存储文件夹（hadoop/tmp/）并重建
  3. 删除Hadoop-2.7.7目录下的日志文件
  4. 执行 `hadoop namenode –format` 格式化Hadoop
  5. 重启Hadoop集群

#### 2.4 MySQL安装步骤
1. 下载并安装MySQL（推荐依赖：libipc-sharedcache-perl、mailx、tinyca）
2. 检查MySQL状态：执行 `service mysql status`
   - 成功状态提示：`Active: active (running) since Sun 2020-10-18 16:40:20 CST`
3. 验证安装结果：执行 `mysql -u root -p`，输入密码后进入MySQL终端
   - 终端提示：`Welcome to the MySQL monitor. Commands end with ; or \g. Your MySQL connection id is 7 Server version: 5.7.21-1 (Debian)`

#### 2.5 Hive安装步骤
1. 从Apache镜像下载Hive（示例路径：archive.apache.org/dist/hive/hive-1.2.1/）
2. 配置环境变量
3. 修改hive-site.xml文件
4. 安装MySQL驱动
5. 验证安装结果：执行 `hive`，成功进入Hive终端（`hive>`）

### 3.2 架构设计（Schema Design）
- 架构类型：星型架构（Star Schema）
- 核心组成：
  1. 事实表（Download Fact）：Time_key（时间键）、Software_key（软件键）、Platform_key（平台键）、Area_key（区域键）、Amount_of_Download（下载量）、Software_avg_mark（软件平均分）
  2. 维度表：
     - 时间维度表（Time）：Time_key（时间键）、Year（年份）、Month（月份）、Day（日）
     - 软件维度表（Software）：Software_key（软件键）、Software_name（软件名称）
     - 平台维度表（Platform）：Platform_key（平台键）、Platform_name（平台名称）、Platform_Website（平台网址）
     - 区域维度表（Area）：Area_key（区域键）、Area_name（区域名称）、Province_name（省份名称）

### 3.3 数据仓库创建与建表（Build DW and Create Tables）
1. 创建数据仓库：`hive> create database SW;`
2. 切换至数据仓库：`hive> use SW;`
3. 建表语句（HQL）：
   ```sql
   -- 软件维度表
   create table Software(
     Software_key STRING,
     Software_name STRING
   ) row format delimited fields terminated by '\t';
   
   -- 下载事实表
   create table DownloadFact(
     Time_key BIGINT,
     Software_key STRING,
     Platform_key STRING,
     Area_key STRING,
     Software_avg_mark float,
     Amount_of_Download BIGINT
   ) row format delimited fields terminated by '\t';
   
   -- 时间维度表
   create table Time(
     Time_key BIGINT,
     Year INT,
     Month INT,
     Day INT
   ) row format delimited fields terminated by '\t';
   
   -- 平台维度表
   create table Platform(
     Platform_key STRING,
     Platform_name STRING,
     Platform_Website STRING
   ) row format delimited fields terminated by '\t';
   
   -- 区域维度表
   create table Area(
     Area_key STRING,
     Area_name STRING,
     Province_name STRING
   ) row format delimited fields terminated by '\t';
   ```

## 四、搭建OLAP可视化Web项目（Build Web Project for OLAP Visualization）
### 4.1 Java Web开发环境搭建
- 开发工具：Eclipse Java EE IDE for Web Developers（Version: Photon Release 4.8.0，Build id:20180619-1200）
- 服务器：Tomcat 9.0.39（镜像源：https://mirrors.tuna.tsinghua.edu.cn/apache/）

### 4.2 Hive连接配置与问题解决
#### （1）连接测试
执行查询验证连接：`select * from DownloadFact`，成功返回下载事实表数据（示例：`downloadfact.amount_of_download=28726, downloadfact.platform_key=003, downloadfact.area_key=0108, downloadfact.software_key=0009`）

#### （2）常见问题及解决方案
| 问题类型                | 解决方案                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| NoClassDefFoundError    | 额外添加jar包：httpclient-cache-4.4.jar、httpcore-4.4.jar、httpmime-4.4.jar、commons-logging-1.2.jar、slf4j-api-1.7.25.jar |
| Connection Refused       | 1. 修改core-site.xml文件，添加配置：hadoop.proxyuser.<用户名>.hosts、hadoop.proxyuser.<用户名>.groups；2. 启动hiveserver2 |
| Table Not Found         | 在Hive数据仓库创建的路径下执行 `hiveserver2` 命令                         |

### 4.4 OLAP功能（OLAP Functions）
支持7类核心操作：
1. Slice（切片）
2. Dice（切块）
3. Drill down and Roll up（下钻与上卷）
4. Moving average and sum（移动平均与求和）
5. Rank（排序）
6. Pivot（透视）
7. Crosstab（交叉表）

### 4.5 Web页面展示（Web Page）
页面核心内容：
- 数据仓库架构展示（Schema Presentation）：展示星型架构中的事实表与四大维度表关系
- 功能选择入口：Slice、Dice、Drill down/Roll up、Rank、Pivot、Crosstab等功能按钮
- 维度信息展示：时间维度（Time_key、Year、Month、Day）、软件维度（Software_key、Software_name）、平台维度（Platform_key、Platform_name、Platform_Website）、区域维度（Area_key、Area_name、Province_name）
