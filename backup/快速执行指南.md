# 快速执行指南

## 一、环境准备

确保已安装以下软件：
- Python 3.x
- Pandas库：`pip install pandas`
- Hadoop 2.7.7 或更高版本
- Hive 1.2.1 或更高版本

### 步骤5：修改数据加载脚本路径（重要！）

编辑 `hive_load_data.hql` 文件，将所有 `/path/to/` 替换为实际路径。

例如，如果项目在 `/home/username/400/`，则修改为：

```sql
LOAD DATA LOCAL INPATH '/home/username/400/hive_data/time_dimension.tsv' 
OVERWRITE INTO TABLE time_dimension;
```

**快速替换命令（Linux）：**
```bash
# 获取当前路径
pwd
# 假设输出为：/home/username/400

# 使用sed替换（请根据实际路径修改）
sed -i 's|/path/to/|/home/username/400/|g' hive_load_data.hql
```

**Windows PowerShell替换：**
```powershell
# 获取当前路径
$currentPath = (Get-Location).Path
Write-Host "当前路径: $currentPath"

# 替换路径（将反斜杠转为正斜杠）
$hivePath = $currentPath -replace '\\', '/'
(Get-Content hive_load_data.hql) -replace '/path/to/', "$hivePath/" | Set-Content hive_load_data.hql
```

## 四、常见问题解决

### 问题1：Python脚本报错 "No module named 'pandas'"

**解决：**
```bash
pip install pandas
# 或
pip3 install pandas
```

### 问题2：Hive无法启动

**解决：**
```bash
# 检查Hadoop是否运行
jps

# 检查MySQL是否运行（Hive元数据库）
service mysql status

# 初始化Hive元数据库（首次使用）
schematool -dbType mysql -initSchema
```

### 问题3：LOAD DATA报错 "File not found"

**解决：**
- 检查文件路径是否正确
- 确保使用绝对路径
- 检查文件权限：`chmod 644 hive_data/*.tsv`

### 问题4：PERCENTILE函数不支持

**解决：**
将 `PERCENTILE` 替换为 `PERCENTILE_APPROX`：
```sql
-- 原来
PERCENTILE(CAST(f.avg_score AS BIGINT), 0.25)

-- 改为
PERCENTILE_APPROX(f.avg_score, 0.25)
```

### 问题5：查询结果为空

**解决：**
- 检查数据是否正确加载：`SELECT COUNT(*) FROM gaokao_admission_fact;`
- 检查WHERE条件是否过于严格
- 查看原始数据：`SELECT * FROM gaokao_admission_fact LIMIT 10;`

## 五、性能优化建议

### 1. 启用Hive优化
```sql
SET hive.exec.dynamic.partition=true;
SET hive.exec.dynamic.partition.mode=nonstrict;
SET hive.exec.parallel=true;
SET hive.exec.compress.output=true;
```

### 2. 使用ORC格式存储（可选）
```sql
-- 创建ORC格式的表
CREATE TABLE gaokao_admission_fact_orc
STORED AS ORC
AS SELECT * FROM gaokao_admission_fact;
```

### 3. 创建索引（可选）
```sql
CREATE INDEX idx_year ON TABLE gaokao_admission_fact(time_key)
AS 'COMPACT' WITH DEFERRED REBUILD;
```
