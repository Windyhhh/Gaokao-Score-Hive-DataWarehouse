## ✅ 七、OLAP查询测试

### 7.1 快速测试查询
```sql
USE gaokao_dw;

-- 测试1：简单查询
SELECT COUNT(*) FROM gaokao_admission_fact;

-- 测试2：JOIN查询
SELECT l.province_name, COUNT(*) as cnt
FROM gaokao_admission_fact f
JOIN location_dimension l ON f.location_key = l.location_key
GROUP BY l.province_name;

-- 测试3：聚合查询
SELECT 
    t.year,
    ROUND(AVG(f.avg_score), 2) as avg_score
FROM gaokao_admission_fact f
JOIN time_dimension t ON f.time_key = t.time_key
WHERE f.avg_score IS NOT NULL
GROUP BY t.year
ORDER BY t.year;
```

### 7.2 完整测试
